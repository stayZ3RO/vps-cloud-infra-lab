## Redaction Standard

Before screenshots are committed, sensitive values are redacted or excluded.

Redacted items include:

- Public IPv4 addresses
- IPv6 addresses
- Tailscale IPs
- Provider account details
- Customer numbers
- Email addresses
- Authentication URLs
- API keys
- SSH keys
- Billing details

## Documentation Purpose

- Implementation proof
- Validation evidence

- Troubleshooting notes
- Phase completion criteria

The goal is to show completed infrastructure work without leaking operational details.
